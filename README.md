# RoyalBrine

**RoyalBrine** is a modern online store built with **React** and **Vite**.  
It is designed as a fast, convenient, and customizable solution for small businesses that want to sell products online without dealing with complex CMS systems.  

👉 **The store is live and fully functional right now.**  (https://royal-brine.vercel.app) (Ukranian language on web-site)

## ✨ Features

- ⚡ **React + Vite** — ultra-fast builds and hot module replacement.  
- 🧩 **Modular architecture** — easy to scale and update components.  
- 📱 **Responsive design** — works seamlessly on desktop, tablet, and mobile.  
- 💬 **Messenger integration** — direct order via Telegram, Viber, or WhatsApp in one click.  
- 🔍 **SEO optimized** — ready for fast search engine indexing.  
- 🎨 **Easy customization** — adjust design and content without deep technical skills.  
- 🛠️ **ESLint + modern plugins** — ensures code quality and maintainability.

## 🛒 Best suited for

- Selling homemade or farm products  
- Launching small online shops  
- Quick business start without complex CMS  

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/TulupaAnton/RoyalBrine.git
cd RoyalBrine



Install dependencies:
npm install


Run development server:
npm run dev


Build for production:
npm run build


Preview production build:
npm run preview
